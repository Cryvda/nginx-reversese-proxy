# Nginx Reverse Proxy Configs

Центральный репозиторий конфигураций обратного прокси для сервисов инфраструктуры (MinIO, Portainer и др.).

## Структура репозитория

- `minio.conf` — конфигурация проксирования запросов к MinIO и Portainer.
- `README.md` — эта документация.

> **Важно:** Файлы в этом репозитории являются «источником истины». Не редактируйте файлы напрямую в `/etc/nginx/conf.d/`. Все изменения вносятся здесь, коммитятся в Git и затем копируются (или линкуются) в рабочую директорию Nginx.

## Требования

- Nginx версии 1.19.0 или выше.
- Доступ на запись в директорию `/etc/nginx/conf.d/`.
- Права sudo для проверки конфигурации (`nginx -t`) и перезагрузки сервиса.
